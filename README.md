# 資產冒險記 Net Worth Adventure

一個把「記帳」變成養成遊戲的個人資產負債追蹤工具。輸入你的資產與負債，一隻可愛的海豹角色會隨著你的淨值成長而升級、進化。

🔗 **線上使用**：把這個 repo 部署到 GitHub Pages 後，網址會像
`https://你的帳號.github.io/repo名稱/`

## 功能

- 🦭 **角色養成**：淨值越高，海豹角色等級越高，光環、配件都會跟著變化；負債比過高時海豹會露出擔心的表情
- 💰 **資產／負債清單**：新增、編輯、刪除項目，支援分類、幣別、日期
- 🧮 **金額欄位可直接算算式**（例如 `1000+250`），會自動計算結果
- 💱 **多幣別支援**：可用 TWD / USD / JPY / CNY / EUR / HKD 記帳，自動換算成台幣加總
- 📈 **成長紀錄**：每週追蹤一次淨值，用曲線圖看長期趨勢，同一週更新不會重複累加
- 💡 **財務觀察**：根據負債比、資產集中度等自動產生一般性理財提醒
- 📥 **Excel 匯入／匯出**：可用 Excel 批次匯入資產負債清單，或匯出完整備份（JSON）之後還原
- ✨ **重複項目清理**：一鍵找出同名重複項目，只保留日期最新的一筆

## 使用方式

1. 打開網頁後，先在「資產」「負債」分頁輸入你的財務項目
2. 到「成長紀錄」分頁按「更新本週紀錄」，開始累積每週的淨值走勢
3. 之後每週回來更新項目金額，系統會自動判斷是「新增」還是「更新既有項目」，避免重複計算

## 資料儲存說明

⚠️ 資料是存在**瀏覽器的本機儲存空間（localStorage）**，不是雲端資料庫：

- 換一台電腦、換一個瀏覽器打開，會是空白的，不會自動同步
- 清除瀏覽器資料（尤其是「Cookie 和其他網站資料」這種合併選項）**可能會把資料一併清掉**
- 建議定期到「備份」分頁下載 JSON 備份檔，換裝置或清資料前先備份一份

## 技術說明

單一 HTML 檔案，前端用 React（透過 CDN 載入，無需建置工具），圖表用 Chart.js，Excel 讀寫用 SheetJS。純靜態網頁，可直接部署到 GitHub Pages、Netlify、Vercel 等任何靜態網站託管服務。
